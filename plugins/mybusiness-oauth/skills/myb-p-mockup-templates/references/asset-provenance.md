# Bundled public assets

- `assets/prototype/media/mybusiness-logo.svg`: public MyBusiness wordmark from
  https://www.mybusiness.co.il/wp-content/uploads/2022/10/logoweb.svg, observed in the product
  header on 2026-09-20. SVG paths and gradient only; no scripts, images, links or private metadata.
  Included for product mockups; the brand remains its owner's mark.
- Assistant and Heebo variable WOFF2 fonts: Hebrew and Latin subsets from public npm packages
  `@fontsource-variable/assistant@5.3.0` and `@fontsource-variable/heebo@5.3.0`.
  SIL Open Font License texts are retained beside the fonts. No runtime download.
- Small interface icons are original inline SVG primitives. Native icons and settings tile
  illustrations are approximated, not an exact reproduction.
- No screenshots, customer imagery, tenant CSS dumps, account information, source maps or
  network captures are bundled. Private comparison evidence stays outside the package.
