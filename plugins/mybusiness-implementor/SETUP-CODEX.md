# MyBusiness — App ID וטוקן

גרסה **1.3.1** מספקת את הסקילים בפלאגין ואת החיבור האישי מגדירים פעם אחת כ-Custom MCP ב-Codex. אין חלון התקנה של MyBusiness, אין תוכנה נוספת להתקין ואין דרישה ל-Python או ל-Bitwarden.

## 1. התקנת הפלאגין

Settings → Plugins → Add → Add plugin marketplace:

| שדה | ערך |
|---|---|
| Source | `https://github.com/AviMYB/mybusiness-plugins.git` |
| Git ref | `main` |
| Sparse paths | ריק |

לחצו Add marketplace, בחרו MyBusiness — App ID וטוקן (mybusiness-implementor) והתקינו אותו. הוספת Marketplace בלבד אינה מתקינה את הפלאגין.

## 2. חיבור המערכת שלכם

ב-Settings → Plugins פתחו Add ובחרו בהוספת MCP מותאם אישית. הטופס נקרא **Connect to a custom MCP**. פותחים אותו מהוספת שרת אישי, ולא מתוך כרטיס הפלאגין.

| שדה בטופס | מה להזין |
|---|---|
| Name | `MyBusiness` |
| Type | **Streamable HTTP** |
| URL | `https://mcp.mbapps.co.il/` |
| Bearer token env var | ריק |

תחת **Headers**, הוסיפו שתי שורות באמצעות **Add header**:

| Key | Value |
|---|---|
| `X-Parse-Application-Id` | ה-App ID של בסיס הנתונים שלכם |
| `X-Parse-API-Key` | טוקן ה-API שהפקתם במערכת |

השאירו **Headers from environment variables** ריק במסלול הזה. לחצו **Save**.

הטוקן שייך לשורת X-Parse-API-Key, לא לשדה Bearer token env var. מזינים אותו רק בטופס ההגדרות, לא בצ׳אט ולא בקובצי הפלאגין. ערכי Headers נשמרים בהגדרות המקומיות של Codex; הטופס אינו הבטחה לכספת מוצפנת. אין לשתף את קובץ ההגדרות עם הטוקן.

## 3. מאיפה משיגים App ID וטוקן?

במערכת: החץ ליד שם המשתמש ← **סביבת פיתוח** ← **Databases** ← בסיס הנתונים שלכם ← **Settings**. העתיקו Application Id. תחת API Keys לחצו Add Key ואז Save, והעתיקו את המפתח שנשמר.

[מדריך עם צילומי מסך](skills/myb-p-getting-started/references/03-connect-with-application-credentials.md). המפתח מעניק גישה מלאה לבסיס הנתונים; ניתן לבטלו באמצעות Revoke.

## 4. בדיקת חיבור

פתחו משימה חדשה ובקשו:

> השתמש ב-MyBusiness: קרא Usage-Guide, בדוק Get-Current-User ו-Get-Schema והצג שמות טבלאות בלי לשנות נתונים.

ודאו שהטבלאות שייכות למערכת שהתכוונתם לחבר. הסקילים יכולים להשתמש בכלי ה-MCP האישי. סימון מחובר ורשימת כלים לבדם אינם הוכחת גישה לנתונים.

## שדרוג מ-1.2.0

סגרו את החלון הישן. הסירו את הפלאגין, לחצו Upgrade ליד mybusiness בלשונית Marketplace והתקינו גרסה 1.3.1. הוסיפו Custom MCP לפי שלב 2 ופתחו משימה חדשה. אם כבר יש שרת אישי MyBusiness, ערכו אותו במקום ליצור כפילות.

הגרסה החדשה אינה מפעילה את החלון הישן ואינה קוראת את פרופיל הכספת. סודות שנשמרו דרך 1.2.0 אינם נמחקים אוטומטית; אפשר למחוק אותם מהכספת בנפרד לאחר בדיקת החיבור החדש.

הסרת הפלאגין אינה מסירה את ה-Custom MCP האישי. להסרתו משתמשים בנפרד במסך MCPs.

## פתרון תקלות

- **אין אפשרות לערוך שרת תחת From plugins:** הטופס שייך לשרת אישי. 1.3.1 אינה מוסיפה שרת באזור זה. הוסיפו Custom MCP.
- **מופיע חלון ההגדרה הישן:** ודאו גרסה 1.3.1 ופתחו משימה חדשה לאחר ההתקנה מחדש.
- **Authenticate / שגיאת הרשאה:** בדקו את שתי שורות Headers, שהערכים שייכים לאותו בסיס נתונים ושהמפתח נשמר ולא בוטל. מסלול זה אינו דורש OAuth.
- **אין כלים:** ודאו שהשרת האישי מופעל. פתחו משימה חדשה; אם הבעיה נמשכת הפעילו מחדש את Codex ובדקו את שגיאת החיבור.

## למה החיבור נפרד?

שרת מתוך פלאגין מנוהל על ידי החבילה. התיעוד מתאר שליטה בהפעלה ובהרשאות כלים, ולא טופס עריכת Headers אישי לשרת הארוז. Custom MCP מאפשר להשתמש בטופס המובנה שהמשתמש שולט בו.

[תיעוד OpenAI — MCP](https://learn.chatgpt.com/docs/extend/mcp?surface=cli) · [מבנה פלאגינים](https://developers.openai.com/plugins/build/plugins)

## בחירה בין שתי אפשרויות

אפשרות OAuth מתקינה MCP עם כניסה בדפדפן. אפשרות App ID וטוקן זו שומרת על חיבור אישי דרך הטופס המובנה. התקינו רק אחת מהן. מסלול להזנת פרטים בשרת ארוז בפלאגין עדיין אינו נתמך כאן.

## הרשאות לפי דרך החיבור

**טוקן API מעניק גישה מלאה למערכת המחוברת. OAuth פועל לפי הרשאות המשתמש.** ב-OAuth יש להפעיל בממשק האדמין, במסך User Settings → MCP Permissions, את סוגי הפעולות המותרים למשתמש. הכלים המתקדמים אינם פתוחים כברירת מחדל: יש לבקש פתיחה מ-MyBusiness, ולאחר מכן לאפשר למשתמש בעל תפקיד Admin את Edit pages and schema וללחוץ Apply. שלב פתיחה זה אינו נדרש בחיבור עם טוקן API.
