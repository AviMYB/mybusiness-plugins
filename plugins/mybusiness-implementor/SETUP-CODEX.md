# חיבור MyBusiness ל-Codex — App ID וטוקן

## אחרי ההתקנה ממסך Plugins

1. ודאו שהתקנתם את **MyBusiness** עצמו, ולא רק הוספתם Marketplace.
2. בחרו בכרטיס הפלאגין את הצעת הפתיחה **הגדרת חיבור MyBusiness — פתח טופס App ID וטוקן**. לחלופין כתבו במשימה חדשה: **פתח את הגדרת החיבור של MyBusiness**.
3. ייפתח חלון מקומי בשם **MyBusiness | הגדרת חיבור ל-Codex**. מזינים את שני הערכים **בחלון הזה בלבד**. לא בצ׳אט, לא בקובץ הפלאגין ולא דרך Authenticate.
4. לחצו **טען פרויקטים מהכספת**, בחרו את הפרויקט שלכם ואז **בדוק ושמור חיבור**.
5. רק לאחר הודעת הצלחה פתחו משימה חדשה ובקשו: **בדוק את חיבור MyBusiness והצג את שמות הטבלאות בלי לשנות נתונים**.

ההתקנה ב-Codex אינה מציגה טופס מובנה עבור שדות userConfig של Claude. לכן הטופס המצורף לפלאגין נפתח מפעולת ההתחלה שלו. הוא אינו נפתח אוטומטית בעת Install.

## מאיפה מביאים את שני הפרטים?

במערכת שלכם: החץ ליד שם המשתמש ← **סביבת פיתוח** ← **Databases** ← בסיס הנתונים שלכם ← **Settings**.

| שדה בחלון | מה מזינים |
|---|---|
| Application ID | הערך שמעתיקים מ-Application Id במסך Settings |
| API token / מפתח API | תחת API Keys לוחצים Add Key ואז Save ומעתיקים את המפתח |

[מדריך עם צילומי מסך](skills/myb-p-getting-started/references/03-connect-with-application-credentials.md).
המפתח מעניק גישה מלאה לבסיס הנתונים. ניתן לבטלו באמצעות Revoke במערכת.

## דרישות חד־פעמיות למחשב

המסלול הזה מיועד ל-**Codex Desktop מקומי ב-Windows**. הוא אינו חיבור ל-ChatGPT בדפדפן.

- Python 3.11 ומעלה, כולל Tkinter, והפקודה `python` זמינה למערכת. בהתקנת Python סמנו Add Python to PATH ואז הפעילו מחדש את Codex.
- [Bitwarden Secrets Manager CLI](https://bitwarden.com/help/secrets-manager-cli/) מותקן כ-`bws` ב-PATH, או תחת `%LOCALAPPDATA%/BitwardenSM/bws.exe`.
- חשבון Bitwarden Secrets Manager, פרויקט ומכונה בעלת הרשאת קריאה וכתיבה לפרויקט. זהו שירות כספת נפרד מ-MyBusiness; אם טרם הוגדר בארגון, יש להכינו תחילה.
- את טוקן המכונה של Bitwarden שומרים ב-**Windows Credential Manager → Windows Credentials → Add a generic credential**: כתובת `BitwardenSM`, שם משתמש `bws`, וסיסמה היא טוקן המכונה. זהו טוקן הכספת, **לא** טוקן MyBusiness. בחלון החיבור בוחרים את אותה רשומה. אפשר גם להשתמש ב-`BWS_ACCESS_TOKEN` שסופק לסביבת ההפעלה באופן מאובטח.

App ID וטוקן MyBusiness נשמרים בכספת בלבד. במחשב נשמרים מזהי הסודות תחת `%LOCALAPPDATA%/MyBusiness/Codex/connection.json`. הסרה והתקנה מחדש של הפלאגין אינן מוחקות את החיבור. להסרת הגישה יש לבטל את מפתח MyBusiness ולמחוק את סודות החיבור מהכספת; הסרת הפלאגין לבדה אינה מבטלת מפתח API.

## אם משהו לא עובד

| מה רואים | מה עושים |
|---|---|
| Authenticate או REPLACE_WITH... | זו החבילה הישנה. Marketplace → mybusiness → Upgrade, ואז הסירו והתקינו את הפלאגין מחדש. ודאו גרסה 1.2.0 ופתחו משימה חדשה. |
| אין כלים כלל | ודאו Python ב-PATH, הפלאגין מופעל ושרת MyBusiness שלו מופעל. הפעילו מחדש את Codex. |
| החלון לא מופיע | בקשו מהסוכן להריץ `python` עם הקובץ `scripts/codex_connection.py` מתוך הפלאגין והארגומנט `setup`. Python חייב לכלול Tk. |
| אין פרויקטים בכספת | בדקו הרשאות מכונת Bitwarden לפרויקט; הרשאת קריאה לבדה אינה מספיקה לשמירה. |
| בדיקת החיבור נכשלת | בדקו שה-App ID והטוקן שייכים לאותו בסיס נתונים, שהמפתח נשמר ולא בוטל. שגיאה אינה אישור שהחיבור עובד. |
| הוגדר חיבור אך אין כלי CRM | פתחו משימה חדשה. אם הבעיה נמשכת, פתחו שוב את טופס החיבור ובדקו את הכספת והמפתח. |

הבדיקה קוראת Usage-Guide, Get-Current-User ו-Get-Schema ואינה משנה רשומות. סימון מחובר או רשימת כלים לבדם אינם הוכחת גישה לנתונים. לפני עבודה ודאו ששמות הטבלאות תואמים למערכת שהתכוונתם לחבר.
