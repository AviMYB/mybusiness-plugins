# 1.4.2 — Native activities and reports

Activities now uses the business-activity filter grid, table and side sheet. Reports now opens with the native saved-report chooser and results table, with a tabbed configuration dialog for columns, labels and filters.

Both screen compositions were compared with the live CRM. All data is synthetic and actions stay local. Existing local demo data is preserved. Advanced report features are explicitly outside the demo. Both plugin variants include the same update; authentication is unchanged.
