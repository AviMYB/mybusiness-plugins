# 1.4.0 — Interactive local mockups

Both MyBusiness plugin variants now include `myb-p-mockup-templates`: twelve interactive screen patterns and fourteen sanitized original visual references. The starter runs locally with Node.js, no package installation, synthetic data and browser-local persistence.

Includes record search/edit, dashboards, settings, board, calendar, wizard, document editor, inbox, reports/CSV, import review, activity and knowledge center. New screen compositions demonstrate proposed interaction rather than guaranteed native CRM capabilities.

The same audited skill files ship in OAuth and App ID/API token variants. Authentication configuration is unchanged. Refresh the plugin marketplace and update the installed variant to receive this version.

Core CRM layouts were compared with the live product on 2026-09-20: white shell, native navigation geometry, search/table layout, full-height left record sheet, dashboard columns, settings tiles and hourly calendar. The gallery is separate from the CRM shell. Assistant/Heebo fonts and the public brand wordmark are bundled locally; no live screenshots or account data ship. Module references and proposed patterns remain explicitly labeled.
